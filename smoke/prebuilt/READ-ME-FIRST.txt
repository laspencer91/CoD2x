SETUP
1. Extract the entire ZIP, keeping its contents together, and open CoD2SmokeTool.exe.
2. Check the detected CoD2 installation, or browse to your CoD2MP_s.exe.
3. Close CoD clients/servers and click Try smoke. It checks compatibility, backs up
   replaced client files, installs smoke and opens Toujane locally with DX9 enabled.
4. Join a team, select a weapon, and throw smoke grenades. Shoot smoke to carve it.

For invited players, use cod2x-smoke-player.zip: it has no baker or Python files.
The full cod2x-smoke-test.zip includes optional map authoring tools. Player actions
also work directly from smoke/prebuilt in the branch, without those authoring files.

Existing installations, including Steam, are supported. No separate game copy or
map bake is needed; the modified CoD2x loader is included. Restore original files
returns the backed-up client. If CoD2x replaces the loader after smoke is installed,
Try smoke saves the newer client for restoration, retaining earlier backups.
Repeat installs otherwise preserve the existing baseline. Tools & details contains
validation and logs and opens on errors. The full ZIP also offers Map authoring
there. WebView2 is required; Python is bundled only in the full authoring package.
See DESKTOP-TOOL.txt for details. A separate game copy is optional for developers.

The scripts remain available: Setup-Smoke-Test.cmd installs, Start-Smoke-Test.cmd
launches, and Uninstall-Smoke-Test.cmd restores previous client files. They also
work directly from smoke/prebuilt in a branch checkout. For a combined CLI action:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\Smoke-Test.ps1 -Action Try

Console commands:
  /cg_drawFPS 1
  /give smoke_grenade_british_mp
  /give ammo
  /exec smoke_look_wide_fx.cfg   (experimental particle mode 2)
  /exec smoke_look_wide.cfg      (mode 0)
  /seta promod_smoke_resolution half

From Command Prompt in the extracted bundle:
  Start-Smoke-Test.cmd -Map mp_burgundy -Look wide_fx
Pass -GameDirectory "C:\Games\Call of Duty 2" to choose a folder explicitly.
PowerShell check without launching:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\Smoke-Test.ps1 -Action Verify

REMOVAL
Close CoD2 and run Uninstall-Smoke-Test.cmd. Original backups are preserved
across reinstalls/updates. Changed installed files or corrupt backups stop removal.
Backups, unrelated files and game-created logs/configs
are retained. No global execution policy or updater endpoint is changed.

CONTENTS
The smoke implementation and HLSL source are not in this snapshot. Runtime uses
the compiled smoke.shaders bundle, DLL and noise texture. The CoD2x bridge source
and build/package scripts are on the local feature/volumetric-smoke branch.
The test bridge disables stable auto-updates so they cannot replace this build.

All 15 stock MP occupancy grids are included in mapkit_smoke_stock.iwd. The 21
custom/test occupancy IWDs are separate and require their exact matching maps.
No stock game executable, renderer, BSPs, textures or models are shipped here.
Six stock grids require cropped-bounds review: Brecourt, Carentan, Decoy, Harbor,
Matmata and Rhine. A passing hash/binding is not a route-coverage guarantee.

Optional authoring tool: tools/smoke-bake in the branch or assembled test ZIP.
It takes compiled BSPs and makes occupancy, not map geometry or lightmaps.
The GUI uses bundled Python; running bake.py manually needs Windows and Python
3.10+. The voxelizer is prebuilt and the world-only exporter needs only the
standard library. Players do not need to run the baker.
