CoD2 Smoke - player preview

1. Extract the entire ZIP and open CoD2SmokeTool.exe.
2. Check the detected CoD2 folder, or use Browse to select CoD2MP_s.exe.
3. Close other CoD clients/servers and click Try smoke.
4. Join a team, throw a smoke grenade, and shoot through it to try carving.

Your existing CoD2 1.3 installation is supported, including Steam. The tool checks
compatibility, backs up replaced client files, installs smoke, and opens Toujane
locally. No separate game copy, Git repo, Python or map bake is required.
Microsoft Edge WebView2 Runtime is required to open the tool.

Restore original files returns the client backed up on the first installation.
Keep the full ZIP contents together until you have restored. Repeated installs
preserve original backups. Setup/restoration retain maps, player configs, backups
and unrelated files. Other CoD clients must be closed before launching.

Tools & details contains validation and the activity log. It opens on errors.
Copy log copies the visible log; nothing is uploaded. TESTING-NOTES.txt describes
known test limitations. This preview has not been approved for competition.

All 15 stock MP smoke occupancy grids are included. Optional custom/test grids
require their exact matching maps. No game executable, renderer, BSP, textures or
models are supplied. This player package contains no map baker or Python runtime,
and no smoke/voxelizer C++ or HLSL source. Installer scripts remain readable.
